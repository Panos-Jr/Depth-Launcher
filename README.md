# <img src="https://github.com/Panos-Jr/Depth-Launcher/blob/main/steering-wheel.png" style="height:2.1rem;vertical-align:middle;margin-right:.6rem;"> Depth Launcher
Client component of the Depth Controller, will restart the game client when the server has fully restarted, requires <a href='https://github.com/Panos-Jr/Depth-Controller/'>Depth Controller</a> to work.

Keep the <b>Depth Launcher</b> in your game files, for example: `C:\Program Files (x86)\steamapps\common\Depth` it should be adject to the Binaries folder
